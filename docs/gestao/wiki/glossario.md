# Glossário

| Palavra | Quer dizer |
|---|---|
| Lojista | Quem tem loja no app e paga o plano |
| Pessoa física | Quem anuncia sem loja (3 anúncios grátis, avulso de R$ 9,90) |
| Radar | Pedidos de compradores que os lojistas veem e respondem com proposta |
| Merc | O robô do app (antigo Aki): atende, ajuda a cadastrar e lê fotos |
| JEV | IA que classifica e confere (categoria, antifraude) |
| Subir | Destaque que leva o anúncio para o topo uma vez |
| Sorte da Região | Números da sorte e sorteio mensal (só com autorização da SPA) |
| SPA | Secretaria de Prêmios e Apostas, do Ministério da Fazenda, que autoriza sorteios |
| Asaas | Serviço que emite Pix, boleto e cartão da mensalidade |
| Evolution | Programa que conecta o número de WhatsApp ao app |
| MCP | Uma tomada que deixa uma IA (Claude, ChatGPT) ler e operar o sistema com permissão |
| PR | Pedido de mudança no GitHub; só entra na `main` com o "sim" do Raniel |
| UTM | Etiqueta no link que diz de onde a pessoa veio (anúncio, story, QR) |
| Ponto de equilíbrio | Quantas lojas pagantes cobrem todos os custos (38 a 47) |
